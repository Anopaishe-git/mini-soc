# Mini-SOC

A hands-on lab project where me and my colleague Lovejoy build a virtual network, attack it
safely, and write our own tools to detect those attacks.

## Tools
Linux (Ubuntu Server, Kali), Nmap, Wireshark, Python, Flask

## Progress
Day 1: VMware lab set up, Ubuntu Server installed, SSH working
Day 2: Linux commands practise to create files and append text on them

## Note
All testing is done on virtual machines we own.
